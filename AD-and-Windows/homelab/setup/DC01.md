# DC01 setup and specs

## Specs

- OS: Windows Server 2019 Core 
- Proxmox VM ID: 102
- RAM: 3GB | Disk: 40GB | CPUs: 2
- NIC: vmbr1 only (homelab network only) (192.168.100.10/24)
- DNS: 127.0.0.1 (points to itself)

## Domain info

- Domain name: lab.local
- NetBIOS name: LAB
- Forest/domain functional level: 2016

## Intentional misconfigurations

- ajones: Pre-authentication disabled, designed for AS-REP roasting

- jsmith: member of the Domain Admins (over-privileged)

- svc_backup SPN: MSSQLSvc/dc01.lab.local:1433 

- svc_sql SPN: HTTP/web.lab.local:80 

## Setup commands used

### Networking and general configurations

```powershell
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.100.10 -PrefixLength 24
```

Used for assigning the server to the lab network with its designated IP.

```powershell
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 127.0.0.1
```

Configuring the DNS to point to loopback, pointing the DNS back to the server itself.

```powershell
Rename-Computer -NewName "DC01" -Restart
```

Renaming the server to `DC01` (stands for Domain Controller) and restarting the server right after.

### AD Domain Controller setup and configurations

```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
```

Installing the AD Domain Services role

```powershell
Install-ADDSForest -DomainName "lab.local" -DomainNetbiosName "LAB" -SafeModeAdministratorPassword (ConvertTo-SecureString "Password123!" -AsPlainText -Force) -Force
```

Promoting the server to domain controller and creating a new forest.

#### Users setup

I've used a script to automate the making and configuration of the users so I don't need to write the commands over and over again.

```powershell
$users = @(
    @{Name="John Smith";   SAM="jsmith";   Pass="Password1"},
    @{Name="Alice Jones";  SAM="ajones";   Pass="Summer2023!"},
    @{Name="svc_backup";   SAM="svc_backup"; Pass="Backup123"},
    @{Name="svc_sql";      SAM="svc_sql";    Pass="SqlService1"}
)

foreach ($u in $users) {
    New-ADUser -Name $u.Name -SamAccountName $u.SAM `
        -AccountPassword (ConvertTo-SecureString $u.Pass -AsPlainText -Force) `
        -Enabled $true -PasswordNeverExpires $true
}

# local admin configuration
Add-ADGroupMember -Identity "Domain Admins" -Members "jsmith"

# Setting SPNs on service accounts for kerberoasting
Set-ADUser -Identity "svc_backup" -ServicePrincipalNames @{Add="MSSQLSvc/dc01.lab.local:1433"}
Set-ADUser -Identity "svc_sql"    -ServicePrincipalNames @{Add="HTTP/web.lab.local:80"}

# AS-REP roasting, disabling pre-auth on that account
Set-ADAccountControl -Identity "ajones" -DoesNotRequirePreAuth $true
```

This sets up 4 users with their designated name, username and password. Later on configuring special configurations for the users (jsmith being an admin, setting SPNs for the service accounts, disabling pre-auth for ajones)
